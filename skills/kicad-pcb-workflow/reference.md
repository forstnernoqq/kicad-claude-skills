# Pipeline details (read only the step you are on)

Commands use `scripts/kcli` (kicad-cli) and `scripts/kpy` (KiCad python with pcbnew). They resolve to the right tools through the platform skill (`kicad-env-*`).

Proven on the WCH-LinkE to TC2030 adapter (2026-11).

1. **Clarify geometry before placing** (this cost several rounds): which connector goes on which edge, right-angle vs vertical vs SMD, whether a stated dimension is width or height, which side parts sit on (e.g. bypass jumpers on the bottom). Ask once, with a recommendation.
2. **Pinouts from physical evidence.** For a module with a double-row header, derive the mapping from photos: mirror between top/bottom photos, then account for the connector's row/column order when plugged in (a right-angle socket: odd pins = the row farthest from the mating face = upper row). Present the pin table to the user for confirmation.
3. **Schematic edits** (conventions, the pin/lint tool and the restructuring procedure are in the `kicad-schematic` skill) can be done as text on the closed `.kicad_sch` (labels with wire stubs per pin, `no_connect`, lib symbol copied from KiCad's stock symbol libraries (path: see the platform skill) with the name prefixed `Lib:Symbol` inside `lib_symbols`). Always run ERC on a copy in the project dir: `scripts/kcli sch erc --severity-all --format json`. To check connectivity, export the netlist (`sch export netlist --format kicadxml`) and compare it with the intended nets.
4. **F8** by the user, then `save_project`; parse pad coordinates from the saved `.kicad_pcb` (pad `at` angle in board files is absolute; swap w/h when angle is 90/270; pad abs pos = fp pos + R(fp rot) * local).
5. **Placement** via Konnect `set_component_placements` (rotation counter-clockwise positive; rot 90 of a part with pins at -x puts them at bottom). Plan with courtyards (`F.CrtYd`) and check rotations by reading pad positions back. Flip to the back with `flip_component` (layer `B.Cu`), then set rotation; bottom-side SMD jumpers keep pad order for rot 0 but verify pad1 side. `add_board_outline` appends, so `delete_graphics` layer `Edge.Cuts` first when resizing.
6. **Autoroute**: `scripts/route.sh board.kicad_pcb workdir` (DSN export, Freerouting headless, import SES, GND pours both layers, thin-track fix, refill). Freerouting necks tracks down to 0.12-0.15 mm at fine-pitch pins: set board `min_track_width` to 0.15 on 2-layer boards (0.1 on dense 4-layer boards) and widen anything thinner; widening to the netclass 0.2 causes tiny clearance violations. Routing took ~8 s for a 20-part board. A hand-rolled grid router was not worth it as the main router, but on dense 4L boards a small A* router (`route4l/miniroute.py`) was the best tool for the last 5-10 connections and local reworks.
7. **Silkscreen**: `scripts/add_silk.py` with a JSON label list. Honour the board's `min_text_height` (0.8 mm here). Hide reference designators with `fp.Reference().SetVisible(False)` if the user does not want them. Check `silk_overlap` / `silk_over_copper` in DRC, move labels off connector outlines.
8. **DRC**: `scripts/kcli pcb drc --severity-all --format json --all-track-errors --schematic-parity -o x.json board.kicad_pcb`; summarise with `scripts/drc_summary.py`. Target: 0 errors, 0 unconnected, 0 parity issues. `lib_footprint_mismatch` warnings are cosmetic.
9. **Handoff to the user**: they usually clean up by hand in KiCad. Work on a copy (`route_job/final.kicad_pcb`) until they say it is done; they may Save As over the project file themselves. Then re-run DRC on the project board.
10. **JLCPCB production files**: `scripts/export_jlcpcb.sh board.kicad_pcb outdir`.
    - It runs DRC with a zone refill, then exports Gerbers: all copper layers including inner ones, mask, paste, silk and outline.
    - Drill files: PTH and NPTH, with an empty NPTH file dropped. Everything is zipped.
    - If the `.kicad_sch` sits next to the board, it also writes `<name>_BOM_JLC.csv` and `<name>_CPL_JLC.csv` (`jlc_assembly.py`). These contain only fitted parts, which needs an `LCSC` field on every assembled symbol, DNP and 'exclude from BOM' set, and pos/BOM exclusions set in the schematic, because F8 overwrites board-only flags.
    - Re-run after every board change: the export reads the saved file only.
    - Write a short `README.md` with the order settings next to the files.
    - Typical settings, 2-layer: 1.6 mm, lead-free HASL. 4-layer: JLC04161H-7628 and ENIG for fine-pitch QFNs.
    - Assembly: top side only when all bottom parts are hand-fit.
    - Tell the user to check JLC's rotation preview for QFN pin 1, SOT-23 parts, diodes and LEDs.
11. **Footprint checks against datasheets**: fetch TI/Samtec PDFs with curl into a fresh scratch dir and `pdftotext -layout` / `pdftoppm` them; compare pad length/row spacing/outer extent, not just pitch. Generic KiCad footprints are often a bit short vs the manufacturer land pattern but usable; say so. Footprints from an old board can be copied into a project `.pretty` with pcbnew python (`io = pcbnew.PCB_IO_KICAD_SEXPR(); io.FootprintSave(dir, fp)`; un-flip, set orientation 0 and position 0, clear net codes first).
12. **BOM**: CSV columns `Project, Description, Mouser Part Number, Quantity, Customer Part Number` (refs). The `Project` field lets the user concatenate CSVs of all designs and sum per Mouser PN. Keep connectors cheap (user preference). Mark any Mouser number that was not seen on a Mouser page as inferred. Keep `BOM.md` and the schematic MPN/Mouser fields in sync.
13. Update `HANDOFF.md` and project memory at milestones.
